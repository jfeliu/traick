Privacy Policy

Last updated: April 9, 2026

This Privacy Policy describes how Traick ("the app", "we", "our") handles information when you use the Traick WhatsApp assistant. Traick is a self-hosted, open-source application — the operator of any given Traick instance is the individual who deployed it, not Anthropic or any other third party.

1. Data We Collect

When a WhatsApp message is sent to a Traick-connected business number, the following data is processed and stored locally:

  • Phone numbers — the sender's WhatsApp phone number, used to scope projects and send replies.
  • Message content — the full text of incoming WhatsApp messages, stored temporarily as raw messages pending AI processing.
  • Extracted data — projects, action items, deadlines, and follow-up schedules derived from message content by Claude (Anthropic's AI model).

2. How We Use Your Data

  • To generate automated replies to incoming WhatsApp messages on behalf of the account owner.
  • To extract and maintain a structured record of projects and action items mentioned in conversations.
  • To send proactive follow-up reminder messages when scheduled deadlines approach.

3. Data Storage

All data is stored in a SQLite database file on the server where Traick is deployed. Traick does not transmit your data to any centralized service operated by this project. Message content is sent to Anthropic's Claude API solely for the purpose of generating replies and extracting structured information; Anthropic's own Privacy Policy applies to that processing.

4. Data Sharing

Traick does not sell, rent, or share personal data with third parties, except:

  • Anthropic — message content is sent to the Claude API to generate replies and extract project data.
  • Meta (WhatsApp) — outbound messages are delivered via the WhatsApp Cloud API. Meta's Privacy Policy applies to message delivery.

5. Data Retention

Data is retained for as long as the Traick instance is operational. The operator of the instance is responsible for managing and deleting data. Raw messages are marked as processed after AI extraction but remain in the database unless manually deleted.

6. Your Rights

If you have sent messages to a Traick-connected number and would like your data removed, please contact the operator of that Traick instance directly.

7. Contact

For questions about this privacy policy, contact the operator via GitHub: github.com/jfeliu/traick.
